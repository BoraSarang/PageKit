PageKit 설정

사이드 패널 열기: ⌘/Ctrl + Shift + K · 우클릭 메뉴 "PageKit으로 분석"

🔓 우클릭/복사 제한 해제

켜면 모든 사이트에서 우클릭·복사·선택 제한을 풉니다. (기본 꺼짐 — 심사 안전)

📌 사이트별 본문 규칙

본문 감지가 안 되는 사이트의 본문 CSS 선택자를 지정합니다. (콤마 구분)

    🔗 링크 프리셋 (정규식)

    특수 링크 조사에 쓰는 정규식 프리셋. 형식: 이름|정규식

      ⚙️ 다운로드 설정

      🔍 페이지 품질 진단

      현재 페이지의 SEO·성능·접근성·콘텐츠 품질을 종합 진단합니다. (사이드패널 '품질 진단' 단독 패널)

      분석 모듈 (선택한 것만 실행)
      임계값 (점수/성능 기준)

      🐞 디버그

      디버그 로그 수집 여부. 끄면 디버그 창(Cmd+Shift+D)이 비어 보입니다.
