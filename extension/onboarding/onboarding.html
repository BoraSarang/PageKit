툴바에 고정하고 시작하세요

🧩
1. 확장 아이콘 찾기

주소창 오른쪽 🧩 퍼즐 아이콘을 클릭하면 설치된 확장 목록이 나옵니다.

📌
2. PageKit 고정

PageKit 옆의 📌 고정 버튼을 클릭하면 툴바에 항상 표시됩니다. (Chrome 메뉴에서 확장 아이콘 우클릭 → "툴바에 고정"도 가능)

⚡
3. 바로가기 확인

툴바 아이콘 클릭 → 사이드 패널이 열립니다. 단축키 ⌘/Ctrl + Shift + K로도 열 수 있어요.

💡 툴바 고정의 이점 — 아이콘 1번 클릭으로 패널 진입 · 스트림 다운로드 진행률(%) 배지를 툴바에서 바로 확인 · 우클릭으로 디버그 창까지 즉시 접근. 고정하면 확장을 매번 퍼즐 메뉴에서 찾지 않아도 됩니다!
1

우클릭/복사 제한 해제

🔓
1. 설정 열기

툴바 PageKit 아이콘 우클릭 → 옵션을 선택합니다. (주소창에 chrome://extensions → PageKit → 세부정보 → 확장 옵션도 가능)

✅
2. "우클릭/복사 제한 해제" 켜기

설정 첫 번째 카드의 체크박스를 ON으로 켜면 즉시 적용됩니다. 새로고침 없이 현재 탭부터 동작해요.

⚠️
3. 참고

사이트가 강한 차단 스크립트를 쓰면 일부 복사가 안 될 수 있습니다. 이때는 페이지 새로고침 후 다시 시도해 보세요.

2

이미지 · 동영상 · 스트림 다운로드

📊
1. 패널 열기 & 자동 분석

툴바 아이콘 클릭(또는 ⌘/Ctrl + Shift + K) → 페이지가 자동 분석됩니다. 탭을 바꾸거나 페이지를 이동하면 패널도 자동으로 다시 분석해요.

🖼
2. 이미지 저장

이미지 탭에서 원하는 이미지를 선택 → 하단 다운로드 클릭. ZIP 체크 시 선택분을 한 번에 묶어 저장하고, 형식·크기 필터와 본문만 표시로 골라 담을 수 있습니다.

📡
3. 스트림 저장 (실시간 감지)

스트림 탭 — 페이지에서 동영상을 재생하면 m3u8/DASH 스트림이 자동 캡처됩니다. 항목 옆 다운로드를 누르면 독립 창에서 병렬로 받아져요. (설정 › 스트림 감지 ON 필요)

🎬
4. 그 외 저장 & 정리

영상(mp4 등 직접 파일) · 오디오 · 링크 탭도 동일한 방식입니다. 링크는 CSV로 내보낼 수 있어요.

💡 어디서든 시작 — 페이지에서 마우스 우클릭 → PageKit으로 분석을 선택해도 패널이 바로 열립니다.
