# PageKit (페이지킷) — 제품 요구사항 정의서

**버전**: v0.1.0 (초안)
**플랫폼**: Chrome Extension (Manifest V3)
**작성일**: 2026-08-14

---

## 1. 제품 개요

> 웹페이지 군더더기는 빼고, 알짜배기 미디어만 쏙! PageKit
> 본문만 깔끔하게 분석하고 다운로드하는 스마트 웹 툴킷

PageKit은 웹페이지를 다루는 필수 도구 모음 올인원 크롬 익스텐션이다.
페이지의 본문 영역을 스마트하게 분석하여, 광고/메뉴 등 군더더기를 제외한
**알짜배기 미디어(이미지·동영상·실시간 스트리밍)만 선별**해 다운로드하고,
특정 형식의 링크를 정밀하게 추출·검색할 수 있는 도구 상자다.

## 2. 타겟 사용자

| 페르소나 | 니즈 |
|----------|------|
| 기사/블로그 독자 | 본문 이미지를 한 번에 저장, 우클릭 제한 불편 해소 |
| 리서처/학생 | 페이지 내 특정 형식 링크(.pdf, .zip) 수집 |
| 콘텐츠 크리에이터 | 이미지·영상 소스 수집, 스트리밍 영상 보관 |
| SEO/마케터 | 페이지 링크 구조 분석, CSV 내보내기 |

## 3. 핵심 기능 (5대 기능)

### F1. 마우스 오른쪽 제한 풀기
- 컨텍스트 메뉴·복사·텍스트 선택·pointer-events 차단 해제
- 사이트별 ON/OFF 화이트리스트 (옵션 페이지)
- alert 등 방해 알림 차단 (선택)

### F2. 스마트 본문 타겟팅
- `@mozilla/readability` 기반 본문 영역 분석 (clone + DOMPurify sanitize)
- 사이트별 preRemove 규칙 + 사용자 커스텀 규칙 (chrome.storage 저장)
- 본문 영역 하이라이트 오버레이 + 드래그 보정 모드
- **본문 내부/외부 분류** — 미디어 리스트업 시 본문 외부(광고/메뉴)는 흐리게 표시

### F3. 미디어 리스트업 & 선택 다운로드
- 이미지: `<img>`/srcset/lazy-load/background-image 수집, 원본 URL 추적
- 동영상: `<video>`/MP4/WebM + HLS(m3u8)/DASH 감지
- 실시간 스트림: 감지 + 품질 선택 + 세그먼트 기록
- 필터: 최소 해상도/크기/형식, 본문 내부만
- 배치 다운로드 + ZIP 패키징 + 폴더 구조 정리
- 다운로드 상태: 진행률/실패/재시도, 툴바 배지

### F4. 특수 링크 조사
- 전체 링크 추출 + 중복 제거 + 앵커 텍스트
- 정규식 필터 + 프리셋(.pdf/.zip/.mp4 등) + 라이브 프리뷰
- 검색 상자 + CSV/JSON/Markdown/클립보드 내보내기

### F5. 지속적 기능 확장
- 모듈형 아키텍처로 기능 추가 용이 (shared/ 추상화)

## 4. UI 구조

| 화면 | 역할 |
|------|------|
| **사이드 패널 (메인)** | 분류 탭(이미지/동영상/오디오/링크/문서/스트림) + 통계 배지, 필터/검색, 다운로드 진행 전체 뷰 |
| **팝업 (보조)** | 분석 실행, 간단 선택, 미니 진행 요약, [사이드 패널 열기] 버튼 |
| **옵션 페이지** | 단축키 안내, 사이트 화이트리스트, 규칙 관리, 프리셋 관리 |

### 사이드 패널 진입점 (5가지 모두 지원)
| # | 진입점 | 구현 |
|---|--------|------|
| ① | 확장 아이콘 클릭 | 팝업 → [사이드 패널 열기] (팝업 유지 구조) |
| ② | 우클릭 컨텍스트 메뉴 | "PageKit으로 분석" |
| ③ | 키보드 단축키 | 기본 Cmd+Shift+K, 사용자 변경 가능 |
| ④ | 팝업 버튼 | [전체 보기 →] |
| ⑤ | 페이지 내 플로팅 버튼 | 요청 시에만 scripting으로 주입 |

## 5. 비기능 요구사항

| 항목 | 기준 |
|------|------|
| 성능 | SW wake ≤500ms, 팝업 ≤300ms, 사이드 패널 60fps |
| 메모리 | SW ≤50MB, 콘텐츠 ≤30MB |
| 권한 | 최소 권한. host_permissions는 요청 시점에만, `<all_urls>` 자동 주입 금지 |
| 보안 | CSP `script-src 'self'`, 시크릿 하드코딩 금지 |
| 언어 | UI 한국어 우선 + 영어, 코드/로그 영어 |

## 6. 심사 대응 (Chrome Web Store)

- [ ] permissions/host_permissions 최소화 — `scripting`, `sidePanel`, `downloads`, `storage`, `contextMenus`, `commands`, `declarativeNetRequest`(선택)
- [ ] content_security_policy `unsafe-eval` 없음
- [ ] 다운로드는 "사용자 선택 기반" UI 필수 (원클릭 전체 다운로드 표현 금지)
- [ ] web_accessible_resources 최소화
- [ ] privacy_policy URL + 개인정보 수집 없음 명시
