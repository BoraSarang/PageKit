# 📸 스크린샷 캡처 가이드

## 저장 후 처리

1. `.github/assets/popup.png` 등 4개 파일 커밋
2. `README.md`의 스크린샷 섹션 주석(`<!-- ... -->`) 해제
3. 미리보기로 이미지 경로 확인 후 푸시

## 권장 규격

- PNG, 폭 800~1200px (사이드패널은 실제 폭 그대도 OK)
- 다크/라이트 중 하나로 통일 (첫 인상용은 라이트 추천)
