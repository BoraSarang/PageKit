우클릭이 막힌 페이지

복사·저장이 잠긴 페이지는 소스 보기도 막혀 있어 답답했습니다. PageKit이 우클릭·복사 제한을 풀어 드립니다.

하나씩 저장하는 수고

이미지가 수십 장이면 한 장씩 저장하기 지겹습니다. 페이지에서 한 번에 수집해 ZIP으로 묶어 드립니다.

쪼개진 영상 조각

HLS·DASH 스트리밍은 수백 개 조각으로 쪼개져 있습니다. PageKit이 조각을 모아 하나의 MP4로 병합합니다.

모든 기능

수집부터 저장까지, 페이지 작업의 전체 흐름을 한 확장으로.

이미지 수집

srcset·lazy·background 이미지까지 감지하고 본문 안/밖 분류 필터로 원하는 것만.

영상 병합 다운로드

HLS(m3u8)·DASH(mpd) 스트리밍을 품질 선택 후 하나의 MP4로 병합. 유튜브도 지원.

배치 ZIP 저장

선택한 항목을 폴더 구조 그대로 ZIP으로 압축. 실패 항목은 자동 재시도.

링크 추출 · CSV

페이지 링크를 중복 없이 추출하고 정규식 필터·프리셋으로 골라 CSV로 내보내기.

우클릭·복사 해제

복사·저장 제한이 걸린 페이지에서도 자유롭게 텍스트와 이미지를 사용하세요.

가볍고 빠른

요청 시에만 스크립트를 주입해 브라우징을 방해하지 않습니다. 최소 권한 MV3.

3단계로 시작

  1. 1

    확장 설치

    웨일 스토어 또는 Chrome 웹 스토어에서 PageKit을 추가하세요.

  2. 2

    페이지 분석

    아이콘 클릭 또는 우클릭 → "PageKit으로 분석". 이미지·영상·링크가 한 번에 모입니다.

  3. 3

    일괄 다운로드

    원하는 것만 선택해 ZIP으로. 영상은 품질 선택 후 MP4로 병합 저장됩니다.
